# Authentication Service

This document provides the parameters and configuration details for the Authentication Service, which is responsible for managing the device's authentication credentials used to connect to the MQTT broker.

## Structure

**Service UUID**: `2e27712d-fe1e-49e7-b5f1-50cf73f57d34`

| Name | UUID | Type | Actions | Description | Default Value |
|---|---|---|---|---|---|
| csr | a1b2c3d4-e5f6-7890-abcd-ef1234567890 | string | read | The Certificate Signing Request (CSR) generated by the device. | - |
| certificate | 615551ac-42a4-48e8-b6d8-7b108d265cdf | string | read, write | The certificate generated from the CSR | - |
| ca | ce7d5fc9-bf7d-42d5-9270-c95385768939 | string | read, write | The CA certificate trusted by the device. | - |
| revoke | aa4124b7-9be2-434d-9a9c-f687bc0c5b6e | boolean | write | A flag to revoke the current certificate. | - |
| expiration | 0e2e7e19-6782-4f6d-90d9-b17303ca857c | string | read, write | The expiration time that will be used to generate the certificate (in seconds) | 1 year |
| status | 62bc2aa2-4c8a-4f26-8d56-65b44cf9b2ae | string | read | The status of the certificate (`valid`, `expired`, `pending`, `revoked`) | - |
